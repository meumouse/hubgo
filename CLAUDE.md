# CLAUDE.md

All project guidelines for this repository live in **[AGENTS.md](AGENTS.md)**.

Read `AGENTS.md` before making any change. It is the single source of truth for:

- Project overview, requirements and repository layout
- Build, dev and translation commands
- PHP conventions (naming, formatting, docblocks, security)
- Architecture rules (bootstrap/lazy loading, REST `hubgo/v1`, schema-driven settings, templates, hooks, integrations)
- Frontend conventions (Vue 3 SPA, Tailwind scoping, REST client, field registry, build output)
- Internationalization workflow
- Versioning, releases and git conventions
- Do / Don't working agreements

Keep both files in sync: when guidelines change, update `AGENTS.md` — this file only points to it.
